# Vertex Client

Welcome to Vertex Client! This project is an Android application built with modern development practices and tools.

## Overview

Vertex Client is a cutting-edge Android application designed to provide seamless user experiences and robust functionality. This repository contains the source code, resources, and documentation for the project.

## Features

- Modern Android architecture
- Efficient performance optimization
- User-friendly interface
- Comprehensive testing suite

## Requirements

- Android API level 21 (or higher)
- Android Studio 4.0 or later
- Java 8 or later
- Gradle 6.0 or later

## Getting Started

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/kreok961-arch/Vertex-client.git
   cd Vertex-client
   ```

2. Open the project in Android Studio

3. Build the project:
   ```bash
   ./gradlew build
   ```

4. Run the application:
   ```bash
   ./gradlew run
   ```
